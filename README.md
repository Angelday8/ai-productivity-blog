# AI生产力指南

## 项目概述

基于 VitePress 构建的静态博客，专注于 AI 工具评测与效率方法论。

## 目标

- SEO 长尾流量获取
- 广告 + 联盟营销变现
- 建立个人品牌

## 内容策略

| 栏目 | 方向 | 频率 |
|------|------|------|
| AI工具评测 | 单款工具深度实测 | 每周 1 篇 |
| 效率方法论 | 工作流、思维框架 | 每周 1 篇 |
| 资源推荐 | 工具合集、模板分享 | 每两周 1 篇 |
| 趋势解读 | AI领域重大事件 | 随时 |

## 技术栈

- VitePress — 静态站点生成器
- Markdown — 内容格式
- 部署：GitHub Pages / Cloudflare Pages

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 部署

### GitHub Pages
1. Push 到 GitHub 仓库
2. GitHub Actions 自动构建部署
3. 设置自定义域名（可选）

### Cloudflare Pages
1. 连接 GitHub 仓库
2. 自动构建部署
3. 自带 CDN + 免费 SSL
